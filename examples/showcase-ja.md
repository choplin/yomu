# 螺鈿 Markdown 表示見本

この文書は、日本語の見出しと本文が正しく表示されることを確認するための
見本です。読みながら端末の幅を変え、同じ内容が画面上部の近くに保たれる
ことも確認してください。

## 日本語の見出し

見出しの文字が欠けず、本文より大きく太く表示され、下に区切り線が描かれる
ことを確認します。

## 幅の狭い画面で折り返される長い日本語の見出し

端末の幅を狭くしたとき、長い見出しが途中で切れず、読める状態を保つことを
確認します。画像として表示できない幅では、端末の文字へ切り替わります。

### 小さい見出しは端末文字

三段階目以降の見出しは画像ではなく、通常の端末文字として表示されます。

## 文章と装飾

通常の文章には、*強調*、**強い強調**、~~取り消し線~~、`行内コード`を
含められます。句読点や括弧（「」）、全角記号もそのまま表示されます。

> 本文は端末文字のまま、理解を助ける要素だけを鮮明に描画します。

## 日本語と折り返しを含む表

| 項目 | 状態 | 説明 |
| :--- | :---: | ---: |
| 日本語 | 対応 | Unicode の表示幅を保ちながら読みやすく描画する |
| 長い内容 | 折り返し | 端末幅を狭めるとセル内で決定的に折り返し、内容を失わない |
| 非対応環境 | fallback | 画像を使えない場合も端末文字ですべてのセルを確認できる |

## 一覧と作業項目

- 日本語の字形を保持する
- 画面幅に応じて配置を更新する
  - 長い項目も内容を失わず折り返す
- 終了時に端末表示を元へ戻す

1. 上から下へ読む
2. 画面を狭くしたり広くしたりする
3. 見出しを画面外へ動かしてから戻す

- [x] 一段階目と二段階目の見出しを画像で表示する
- [x] 三段階目以降を端末文字で表示する
- [ ] 後の段階で注釈機能を追加する

## 移動の確認

ここまで移動できれば、長い日本語文書でも上下移動が機能しています。
先頭へ戻るには `g`、末尾へ移動するには `G`、終了するには `q` を押します。
